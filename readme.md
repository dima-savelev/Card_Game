# Klondike Solitaire (Косынка) на Unity & C#

[![Unity Version](https://img.shields.io/badge/Unity-2022.2.16f1-blue.svg)](https://unity.com/)
[![Language](https://img.shields.io/badge/C%23-10%2B-green.svg)](https://docs.microsoft.com/en-us/dotnet/csharp/)
[![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey.svg)]()

Классическая карточная игра **«Косынка» (Klondike Solitaire)**, разработанная в качестве дипломного проекта по специальности *«Информационные системы и программирование»* (РГРТУ, 2023 г.). Проект выполнен с соблюдением модульной архитектуры, содержит реализацию кастомной логики Drag & Drop, валидации карточных последовательностей, системы автозавершения (Auto-Stack) и бинарной сериализации сохранений.

---

## 📌 Ключевые особенности и механики

- **Физика и Drag & Drop:**
  - Реализован плавный перенос карт через систему Raycast и математическую плоскость `Plane` камеры без использования физических Rigidbody, что исключает рассинхронизацию интерфейса.
  - Поддержка перетаскивания как отдельных карт, так и собранных стопок («семейств» карт) с корректным пересчетом `sortingOrder` спрайтов.
  - Анимация возврата карты на исходную позицию при ошибочном ходе (с использованием `DOTween`).
- **Игровая логика и правила «Косынки»:**
  - Автоматическая генерация колоды из 52 карт и честное тасование по алгоритму Фишера — Йетса (`ShuffleDeck`).
  - Раскладка на 7 игровых столбцов с расчетом скрытых/открытых карт.
  - Валидация перемещения в базовые стопки (Foundation) от туза до короля по мастям и в игровые ячейки (Tableau) с чередованием цветов по убыванию.
- **Алгоритм автосбора (Auto-Stack):**
  - Определение момента, когда все карты на столе открыты, и запуск корутины автоматического раскладывания оставшихся карт по основаниям.
- **Сохранение прогресса и настройки:**
  - Сериализация рекордов (лучшее время сборки) в бинарный формат через `FileStream` и `BinaryFormatter`.
  - Управление звуком и разрешением экрана с сохранением настроек через `PlayerPrefs`.

## 🛠 Технологический стек

- **Движок:** Unity `2022.2.16f1`
- **Язык программирования:** C#
- **IDE:** Microsoft Visual Studio 2022
- **UI:** Unity UI, TextMeshPro, кастомные 2D-спрайты
- **Анимации:** DOTween (DoMove для возврата и перемещения карт)
- **Архитектурные концепции:** Component-based architecture, Coroutines (асинхронные тайминги сдачи и автосбора), Queue / рекурсивный обход иерархий `Transform`.

## 📂 Архитектура скриптов

Логика проекта разбита на функциональные модули:

| Скрипт | Назначение |
|---|---|
| `CardManager.cs` | Генератор колоды, тасование, инициализация стопок на старте, раздача карт из колоды (`DealFromDeck`), управление структурой стола. |
| `PlayerInput.cs` | Обработка кликов и свайпов мышью, детекция коллизий через лучи (Raycast), логика проверки допустимости хода (`Stackable`), анимации и вызов экрана победы. |
| `Selectable.cs` | Состояние конкретной карты или слота (рубашка вверх/вниз, масть, ранг, принадлежность к столбцу или колоде). |
| `TriggerCard.cs` | Отслеживание пересечений коллайдеров при сбросе карты для определения целевого слота. |
| `ManagerGame.cs` | Контроллер игрового таймера, загрузка рекордного времени и переключение сцен. |
| `Settings.cs` | Менеджер настроек разрешения экрана, полноэкранного режима и громкости звукового сопровождения. |
| `Save.cs` | Сериализуемый класс данных (`[System.Serializable]`) для сохранения лучших результатов. |

## 🚀 Запуск и тестирование проекта

### Вариант 1. Открытие в Unity Editor
1. Убедитесь, что установлен **Unity Hub** и версия Unity **2022.2.16f1** (или более поздняя совместимая версия 2022 LTS).
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ВАШ_НИКНЕЙМ/название-репозитория.git
   ```
3. Добавьте проект в Unity Hub через кнопку **Add** -> выберите корневую папку.
4. Откройте стартовую сцену из папки `Assets/Scenes/` (главное меню) и нажмите кнопку **Play**.

### Вариант 2. Запуск готового билда (.exe)
- Готовую сборку под Windows можно скачать в разделе **[Releases](https://github.com/)** *(прикрепите ссылку на релиз, если соберете standalone-билд)*.
- Распакуйте архив и запустите файл `Kosynka.exe`.
